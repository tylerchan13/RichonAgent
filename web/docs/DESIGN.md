# Richon Agent interface

Visual reference: `design-concept.png`, generated using the built-in image tool after the user requested Hong Kong financial restraint, Apple-like spacing, and no green.

Tokens: background #fafafa, surface #ffffff, ink #202226, muted #85888e, borders #e4e5e8, champagne #b69b77. Primary buttons are graphite. No green, purple or colored metric tiles. DM Sans, Noto Sans SC, and system sans-serif fallbacks. Main heading 46px desktop / 36px mobile. Navigation 13px desktop / 11px mobile. Body and control type is deliberately compact.

Composition: 76px top navigation; centered content with 48px desktop gutters; large editorial heading and two explicit actions; dataset strip; four metrics divided by hairlines; two-thirds trend panel and one-third observations; paired products and region panels. Corners 6–9px, minimal shadows. Native SVG chart and lucide outline icons. No screenshot-based interface.

Intentional functional adaptations: Chinese UI copy; accurate original dataset totals and group labels; region filter; a note identifying synthetic data and display-only currency; dynamic recommendations that disclose rule-based generation; field mapping with data validation; dataset detail and report pages; two-column metrics and stacked panels on mobile. Added copy serves these required workflows.

Navigation: #overview, #dataset, #report. Primary controls: upload file, confirm mapping, switch dataset, filter region, revenue/profit chart toggle, search/paginate data, export Markdown, print report. All controls have keyboard focus states. Native modal handles focus trapping and Escape, and restores the invoking control. Reduced motion is respected.
